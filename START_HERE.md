# LogLens

1. Extract this ZIP completely before opening files.
2. Open README.md for setup, demo and testing instructions.
3. Run the demo and tests on your computer before publishing.
4. Read docs/DESIGN.md to understand the implementation and tradeoffs.
5. In GitHub Desktop, choose File > Add local repository and select this folder.
6. If prompted, choose Create a Repository here. Keep the existing README and licence.
7. Review the files. Do not add private data, passwords, generated build folders or API tokens.
8. Commit using: `Add LogLens initial version`.
9. Choose Publish repository. Untick Keep this code private if you want recruiters to view it.
